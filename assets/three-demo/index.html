连接西门子 S7 PLC / PLCSIM

真实 PLC 硬件必查清单：
  • 1. 电脑网卡与 PLC 处于同一局域网（能够 ping 通）
  • 2. 博途 CPU 属性【保护与安全】中勾选：“允许来自远程对象的 PUT/GET 通信访问”
  • 3. DB1 数据块属性中取消勾选【优化的块访问】（必须是非优化 DB）
  • 4. 下载 TwinIO 生成的 DB1 到 PLC，且 CPU 处于 RUN 状态

支持直连实体 S7-1200/1500/300 或虚拟 PLCSIM Advanced（原生 S7comm 端口 102）。
